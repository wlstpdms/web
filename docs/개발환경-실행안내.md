# 개발 환경 및 실행 안내

## 서버 실행 원칙

- 프론트엔드와 백엔드 개발 서버는 사용자가 직접 실행하고 종료합니다.
- Codex는 별도 요청이 없는 한 개발 서버를 실행하거나 종료하지 않습니다.

## 백엔드

- FastAPI 앱 진입점: `app.main:app`
- 주소: `http://127.0.0.1:8000`
- 저장소 루트에서 실행: `python main.py`
- 루트 `main.py`는 위 FastAPI 앱을 Uvicorn으로 실행하도록 설정되어 있습니다.

## 프론트엔드

- 폴더: `frontend`
- API 호출은 프런트에서 백엔드(`http://localhost:8000` 또는 `http://127.0.0.1:8000`)로 직접 전송합니다. Vite 프록시는 사용하지 않습니다.
- [frontend/.nvmrc](../frontend/.nvmrc)에 지정한 Node.js 버전은 `22.23.3`입니다.
- Windows 터미널에서 `frontend` 폴더로 이동한 뒤 다음 명령으로 실행합니다.

```powershell
nvm use 22.23.3
npm run dev
```

## 확인된 Node.js 이슈

- 확인 당시 NVM 기본 버전은 `vnone`이었고, `npm` 실행 시 활성 Node.js 버전이 없다는 오류가 발생했습니다.
- 설치된 버전 목록에는 `22.23.3`이 있었지만, Codex 실행 환경에서 `nvm use 22.23.3`을 호출한 뒤에도 `npm`은 계속 같은 오류를 냈습니다.
- 프론트가 시작되지 않으면 Windows 터미널에서 `nvm use 22.23.3`이 성공했는지 먼저 확인한 뒤 `npm run dev`를 다시 실행합니다.

## 이번 작업 요약

- 프론트의 백엔드 주소를 `127.0.0.1:800`에서 사용자가 정정한 `127.0.0.1:8000`으로 설정했습니다.
- 저장소 루트 `main.py`의 예제 출력 코드를 FastAPI 서버 실행 코드로 교체했습니다.
- 다음 세션에도 서버를 직접 실행한다는 원칙과 API 주소를 기억하도록 루트 `AGENTS.md`에 기록했습니다.
- 개발 서버는 실행하지 않았습니다.

## 카카오 로그인

- 프론트엔드 JavaScript 키와 `frontend/.env.local`은 필요하지 않습니다.
- 백엔드 루트 `.env`에 `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_REDIRECT_URI`를 설정합니다.
- 설정 및 Kakao Developers 등록 절차는 [카카오 로그인 안내](kakao-login.md)를 참고합니다.
